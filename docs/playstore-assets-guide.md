# Coffee Hub Play Store Assets Guide

Prepared on: May 6, 2026

This guide is for design and publishing prep only. No images were generated in this pass.

## Required store assets

### App icon

- Size: 512 x 512 px
- Format: 32-bit PNG
- Max file size: 1024 KB
- Recommendation:
  - use the existing Coffee Hub brand mark on a clean background;
  - avoid tiny text;
  - keep high contrast for small-device visibility.

### Feature graphic

- Size: 1024 x 500 px
- Format: JPEG or 24-bit PNG
- No alpha
- Recommendation:
  - show the Coffee Hub brand clearly;
  - emphasize ordering plus delivery;
  - avoid clutter and tiny UI screenshots;
  - use a warm coffee-toned palette consistent with the app.

### Phone screenshots

- Minimum required for listing: at least 2 phone screenshots
- Recommended set: 5 to 8 screenshots
- Format: JPEG or 24-bit PNG
- Dimension rule: each side must be between 320 px and 3840 px, and the longer side cannot exceed twice the shorter side
- Recommended export target:
  - 1080 x 2400 px for portrait screenshots
  - 1242 x 2688 px also acceptable if captured from a high-density device

## Suggested screenshot sequence

1. OTP sign-in screen
   - Caption: `Secure OTP sign-in for fast ordering`
2. Home or menu discovery screen
   - Caption: `Browse coffee, tea, snacks, and daily picks`
3. Cart and checkout screen
   - Caption: `Add favorites and confirm your delivery details`
4. Delivery location or checkout confirmation
   - Caption: `Use location to place accurate local delivery orders`
5. Order tracking screen
   - Caption: `Track your order in real time`
6. Admin dashboard
   - Caption: `Manage orders and menu updates from one system`
7. Delivery agent workflow
   - Caption: `Support faster handoff and delivery operations`

## Store creative recommendations

- Keep customer-first screenshots at the front of the sequence.
- Use later screenshots for admin and delivery features so the listing still reads like a customer app.
- Use consistent framing, typography, and Coffee Hub brand colors.
- Avoid promotional claims you cannot support with current live functionality.
- Do not show placeholder data, broken maps, or debug UI.

## Splash branding guidance

- Keep the splash screen simple, dark, and brand-consistent with the current shell.
- Use the Coffee Hub icon or wordmark centered with strong contrast.
- Avoid long taglines or dense text.
- Ensure the splash art matches the launcher icon family.

## Manual designer checklist

- Export a 512 px high-resolution Play icon, not the adaptive icon layers from Android Studio.
- Prepare screenshots from a signed release or production-like environment.
- Blur or replace real customer phone numbers, addresses, and internal admin data in screenshots.
- Recheck screenshots after final version name, pricing, and menu copy are locked.
